How to choose a Mega

For wild catching: match at least one type of the featured Pokémon. Higher Mega Levels give better Candy XL chances.

For raid catches: any active Mega can give extra ordinary Candy. Match the raid Pokémon's type to get the Candy XL chance bonus.

For Max Battles: don't assume a Mega is needed. You cannot use Megas as Max Battle participants.

Important: the event recommendations are based on known featured catch types, not predictions of all spawns. Confirm bonuses and raid boss availability in-game.

Protect your tracker data

Changes are saved on this device in this browser. This is a web planner, not a Pokémon GO account connection. Your collection is stored locally in this browser on this website. Browsers can clear local data, especially if you move the HTML file; periodically export a backup.

📡 When deployed to GitHub Pages with its included automated update, the event calendar checks a daily refreshed public feed. Unidentified Pokémon types are marked as unknown rather than guessed. Your Mega evolutions and cooldowns must still be entered manually. Never log into your Pokémon GO account through this tool.

Event updates & manual events

Automatically imported events appear alongside events you add yourself. For automatic events without known Pokémon types, no confident Mega recommendation is given. You can add personal reminders using Calendar → + Add event.
